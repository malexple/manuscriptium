# Каталог функций Typora для Manuscriptium Editor

> Назначение: однозначный перечень поведения, которое должен воспроизвести собственный Canvas-редактор Markdown. Источник — публичная документация [https://support.typora.io/](https://support.typora.io/). Текст Typora не копируется; описания даны своими словами. Код Typora не используется (закрытый).
> Приоритеты: **P0** — обязательно (MVP 1), **P1** — MVP 1.5, **P2** — желательно, **P3** — потом/плагин, **M** — собственная фишка Manuscriptium.
> Каждая функция имеет идентификатор `F-xxx`; фазы плана (документ `EDITOR_CANVAS_PLAN.md`) ссылаются на них.

## 0. Строгие ограничения (Strict Constraints)

- Запрещены `JavaFX`, `JCEF`, `WebView`, встроенные браузеры внутри редактора.
- Запрещено заменять кастомный `JComponent`-canvas на `JTextPane`, `JEditorPane`, `RSyntaxTextArea`.
- Запрещены тяжеловесные AWT-компоненты поверх canvas.
- В модуль `spi` нельзя добавлять внешние зависимости (только JDK 21); типы `flexmark`, CSS-парсера не попадают в `spi` — только DTO и интерфейсы расширения.
- Дисковый I/O, парсинг больших файлов, декодирование изображений, генерация формул/диаграмм — не в `EDT`.
- Ввод одного символа не вызывает пересчёта всего документа: только инкрементально изменённые блоки и видимый `Viewport`.
- Нельзя молча перезаписывать, переформатировать, удалять неизвестные поля `YAML Front Matter`, symlinks и исходный Markdown при навигации или смене режима.
- Запись `.md` только атомарно через временный файл (как принято в `core`).
- Без заглушек `// TODO: implement` и сокращённого кода.

## 9. Эталонные темы для приёмки

Встроенные: GitHub, Newsprint, Night, Pixyll, Whitey, Vue. Из галереи `theme.typora.io`: Lapis или Ursine; OneDark или Dracula; Notion или Nord. Тема считается «поддержанной», если открывается без исключений, цвета/шрифты/отступы/границы/фоны применены, неподдерживаемые правила записаны в журнал (F-089).
